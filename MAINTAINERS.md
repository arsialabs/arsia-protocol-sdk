# Maintainers

This file lists the current maintainers of the ARSIA Protocol SDK.
Maintainers have write access to the repository and are responsible for
reviewing and merging pull requests, triaging issues, and cutting releases.

## Becoming a maintainer

Maintainers are appointed by the steward based on sustained,
high-quality contributions over time. There is no formal application
process at this stage. If you are interested in contributing at a
maintainer level, start by opening pull requests and participating in
code review on existing ones — see [CONTRIBUTING.md](./CONTRIBUTING.md).
