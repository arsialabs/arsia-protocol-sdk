Agent B — Anonymizer

agent:meddata.anonymizer

Agent C — Clinical Analyzer

agent:meddata.clinical-analyzer
Anonymized only — PII structurally absent
✗ Patient Name
✗ Date of Birth
✗ Health Number
✓ Lab Values
✓ Anonymization Token
✗ Diagnosis & Report
The protocol guarantees Agent C never sees PII — not because of access control, but because the data is structurally absent from the envelope. Agent B receives PII only to anonymize it; the token it produces cannot be reversed to recover identity.
